File Recovery is a free, open-source tool that helps you find and recover deleted files from your computer, USB drives, and other storage devices.

Recover documents, photos, videos, spreadsheets, and more using a simple, easy-to-use interface.

## ✨ Features

- **Quick Search** — Find deleted files using file system records. Recover original filenames and folder structures when available.
- **Deep Search** — Scan your drive for file signatures, even when original file records are missing.
- **File Type Filters** — Search for specific file types instead of going through thousands of unrelated files.
- **Folder & Date Filters** — Narrow down your search to find files more easily.
- **File Preview** — Inspect supported files before recovering them.
- **Multiple Storage Devices** — Supports internal drives, USB drives, SD cards, and other supported storage devices.
- **Easy-to-Use Interface** — No technical knowledge required.
- **100% Free & Open Source** — No subscriptions or hidden fees.

## 🚀 How to Recover Deleted Files

1. Download and launch File Recovery.
2. Select the drive where your files were stored.
3. Choose **Quick Search** or **Deep Search**.
4. Select the file types you want to recover.
5. Start scanning and review the results.
6. Select your files and click **Recover**.
7. Save the recovered files, preferably to a different physical drive.

## 🔍 Quick Search vs. Deep Search

| Quick Search | Deep Search |
|---|---|
| Uses file system records | Scans for file signatures |
| Usually faster | More thorough, but slower |
| Can preserve original filenames | Original filenames are usually lost |
| Best when file records survive | Useful when file records are missing |

## ⚠️ Important Recovery Tips

**Stop using the affected drive as soon as possible.**

Downloading, installing, or saving new files may overwrite deleted data and reduce your chances of successful recovery.

Whenever possible, save recovered files to a different physical drive.

**Note:** File recovery is not guaranteed. Results depend on the condition of the storage device, whether data has been overwritten, and factors such as SSD TRIM.
